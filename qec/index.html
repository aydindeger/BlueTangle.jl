Quantum error correction

A stabilizer code stores logical information in the simultaneous +1 eigenspace of commuting Pauli operators. An error can change their measurement outcomes without revealing the encoded amplitudes. The resulting syndrome identifies a candidate recovery operation.

BlueTangle constructs an encoding circuit from independent, commuting +1 Pauli generators. Its built-in decoder searches for a matching single-qubit Pauli error. This is sufficient for the example below; it is not a decoder for arbitrary multi-qubit errors, and setting d=3 does not independently certify a code's distance.

Encode an arbitrary logical qubit

The five-qubit code has four independent generators, leaving one logical qubit. Commas separate the physical qubits in each generator.

using BlueTangle, LinearAlgebra

stabilizers = [
    "X,Z,Z,X,I",
    "I,X,Z,Z,X",
    "X,I,X,Z,Z",
    "Z,X,I,X,Z",
]
code = StabilizerCode(stabilizers; d=3)
logical = normalize(ComplexF64[1, 0.2 + 0.7im])
encoded = code.encode(logical)

@assert code.decode(encoded) ≈ logical
@assert all(s -> isapprox(expect(encoded, string_to_matrix(s)), 1), stabilizers)
(data_qubits=code.n, logical_qubits=code.k, syndrome_bits=code.m)
(data_qubits = 5, logical_qubits = 1, syndrome_bits = 4)

code.encode() prepares logical zero. Passing a statevector prepares its arbitrary logical superposition. The physical logical-Pauli representatives are defined by the constructed encoder; supplied logical-operation definitions take precedence.

Inspect and correct a physical error

Apply a Y error to physical qubit 2, measure the generators, and inspect the proposed correction:

damaged = apply(encoded, Op("Y", 2))
measured, bits, candidate = code.syndrome(damaged)
@assert candidate isa Op
(syndrome=bits, correction=(candidate.name, candidate.qubit),
  qubits_after_extraction=get_N(measured))
(syndrome = [1, 1, 0, 1], correction = ("Y", 2), qubits_after_extraction = 9)

The bits follow the input generator order: 0 denotes eigenvalue +1 and 1 denotes eigenvalue −1. code.syndrome appends four ancillas and resets them after reading the syndrome, so the returned state contains nine qubits.

The compact text diagram below shows just the injected error and the selected Pauli correction. Syndrome extraction between them is implicit; encoding and decoding are omitted from this small diagram.

plotq(QuantumOps[Op("Y", 2), candidate]; nqubits=5)

corrected = code.correct(measured, bits)
recovered = code.decode(corrected)
fidelity_after_recovery = abs2(dot(logical, recovered))
@assert isapprox(fidelity_after_recovery, 1; atol=1e-12)
fidelity_after_recovery
0.9999999999999991

The fidelity comparison ignores an irrelevant global phase. decode accepts the five data qubits alone or the data plus reset syndrome ancillas. For a pure state, it checks that discarded wires are in zero rather than silently throwing away unresolved information.

For a complete recovery cycle without inspecting the record:

recovered_directly = code.decode(code.correct(damaged))
@assert isapprox(abs2(dot(logical, recovered_directly)), 1; atol=1e-12)

A zero syndrome means no detected error. Some multi-qubit errors have a zero syndrome or share a syndrome with a single-qubit error and can change the logical state. A syndrome outside the decoder's search raises an error.

Apply a logical gate

Here the qubit index refers to the logical register:

logical_X = code.apply(encoded, "X", 1)
decoded_X = code.decode(logical_X)
@assert decoded_X ≈ gate.X * logical

Use apply(encoded, Op("X", physical_qubit)) when you intend a physical operation instead. A physical error and a logical gate act on different objects even when both are called X.

Correct an ensemble of errors

A density matrix can describe a mixed logical input and a classical mixture of physical errors. The following mixture contains no error, X₁, or Y₄, each of which is correctable by this code:

using BlueTangle, LinearAlgebra
code = StabilizerCode([
    "X,Z,Z,X,I", "I,X,Z,Z,X", "X,I,X,Z,Z", "Z,X,I,X,Z"
]; d=3)
logical_rho = ComplexF64[0.6 0.2+0.1im; 0.2-0.1im 0.4]
encoded_rho = code.encode(logical_rho)
noisy_rho = 0.55encoded_rho +
            0.25apply(encoded_rho, Op("X", 1)) +
            0.20apply(encoded_rho, Op("Y", 4))
recovered_rho = code.decode(code.correct(noisy_rho))
@assert recovered_rho ≈ logical_rho
(trace=real(tr(recovered_rho)), error=norm(recovered_rho-logical_rho))
(trace = 0.9999999999999986, error = 1.1356067500511315e-15)

code.correct(rho) sums the projected syndrome sectors and their corrections deterministically. Calling code.syndrome(rho) instead selects one Born outcome and returns its conditional state and record:

conditional_rho, bits, candidate = code.syndrome(noisy_rho)
recovered_branch = code.decode(code.correct(conditional_rho, bits))
@assert recovered_branch ≈ logical_rho
@assert isapprox(real(tr(conditional_rho)), 1; atol=1e-12)

Density-matrix decoding traces out the other wires. This differs from pure-state decoding, where discarding an entangled wire cannot produce another pure vector.

Use an MPS without converting to a dense vector

Encoding, syndrome extraction, correction, and decoding also accept MPS inputs:

using BlueTangle
code = StabilizerCode([
    "X,Z,Z,X,I", "I,X,Z,Z,X", "X,I,X,Z,Z", "Z,X,I,X,Z"
]; d=3)
logical_mps = plus_state(N_MPS(1))
encoded_mps = code.encode(logical_mps)
damaged_mps = apply(encoded_mps, Op("Y", 2))
recovered_mps = code.decode(code.correct(damaged_mps))
@assert recovered_mps isa it.MPS
@assert isapprox(abs2(inner(logical_mps, recovered_mps)), 1; atol=1e-10)
get_N(recovered_mps)
1

The MPS path samples a syndrome like a statevector trajectory. It can still become expensive when the encoding and recovery circuits generate large bond dimensions; a small example succeeding is not a scaling guarantee.

BlueTangle.StabilizerCode — Type
StabilizerCode(stabilizers::Vector,logicals::Dict)

Construct a code from independent commuting +1 Pauli generators. Rows may
contain I, X, Y, and Z. Automatically derived logical gates respect the
encoder's phases; explicitly supplied mappings are retained.

`code.syndrome(state)` returns the measured state with reset ancillas, the
syndrome bits in the input-generator order, and a candidate single-qubit
correction. `code.correct` uses this bounded decoder. Pure-state `code.decode` requires
the discarded qubits to be in |0⟩ after inverse encoding; it does not silently
project an uncorrected state into a pure logical vector.

Density matrices encode and decode by linear evolution and partial trace.
`code.syndrome(rho)` samples a selective record, while `code.correct(rho)`
sums the recovered syndrome sectors deterministically. MPS preparation,
logical gates, syndrome extraction and correction stay in tensor form.

logicals=Dict()

logicals["I",1]=[("I",1)]
logicals["I",2]=[("I",1)]

logicals["X",1]=[("X",1),("X",2)]
logicals["X",2]=[("X",1),("X",4)]
logicals["Z",1]=[("Z",1),("Z",4)]
logicals["Z",2]=[("Z",1),("Z",2)]
logicals["CNOT",1,2]=[("SWAP",3,4)]
logicals["CNOT",2,1]=[("SWAP",3,4),("SWAP",2,4),("SWAP",1,2)]

stabilizers=[
    ("X,X,X,X"),
    ("Z,Z,Z,Z")
]

stabilizers=[
    ("X,X,X,X,I,I,I"),
    ("X,X,I,I,X,X,I"),
    ("X,I,X,I,X,I,X"),
    ("Z,Z,Z,Z,I,I,I"),
    ("Z,Z,I,I,Z,Z,I"),
    ("Z,I,Z,I,Z,I,Z")
]

code=StabilizerCode(stabilizers,logicals)

fields(code)

BlueTangle.qec_state_prep — Function

qecstateprep(n::Union{Int,Vector},logicalindices::Vector,stateinitsym::Symbol=:zero;randomop_count::Int=20)

If you want QECState to also build the encoded state, pass encoding_circuit=... to the constructor so it can relabel away SWAPs and return the final qubit mapping. stateinitsym supports :zero, :one, :plus, :minus, :zeroplus, :random, :gaussian (or :matchgate) :gaussian starts from a random half-filled computational basis state on the logical qubits. randomu3_count randomly picks count logical qubits and prepares them as random U3|0⟩ product states.
