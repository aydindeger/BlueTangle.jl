BlueTangle.jl

BlueTangle simulates quantum circuits with gates, noise, mid-circuit measurements, and classical feed-forward. Statevectors, density matrices, matrix product states, and Clifford-augmented matrix product states share the same circuit description. Stabilizer-code tools add encoding, logical operations, syndrome extraction, and recovery.

Start with a Bell pair

using BlueTangle
ops = [Op("H", 1), Op("CX", 1, 2)]
state = apply(zero_state(get_N(ops)), ops)
@assert correlation(state, "Z,Z", [1, 2]) ≈ 1
@assert correlation(state, "X,X", [1, 2]) ≈ 1
(state=state, ZZ=correlation(state, "Z,Z", [1, 2]))
(state = sparsevec([1, 4], ComplexF64[0.7071067811865475 + 0.0im, 0.7071067811865475 + 0.0im], 4), ZZ = 0.9999999999999998)

Tuple shorthand for circuits

Anywhere BlueTangle expects an operation list—apply, measure, sample, shadow, camps, phasepoly, route, plotq, to_qasm, get_N, get_stats, get_layers, hilbert, and variational_apply—you can omit Op(...) and write tuples directly (each tuple t is expanded via Op(t...)):

# Equivalent tuple shorthand (single-qubit, two-qubit, parameterized, 3-qubit, reset/measure)
bell = [("H", 1), ("CX", 1, 2)]
@assert apply(bell) ≈ state
m = measure(bell, 1000; backend=:camps)

# Tuples can also be mixed freely with Op(...), ifOp(...), and OpQC(...)
mixed = [("H", 1), ("CX", 1, 2), Op("Z", 2; control=1), ifOp("MZ", 1, "I", "X")]
get_stats(mixed)
(N = 2, len = 4, depth = 4, cx_count = 1, swap_count = 0, two_qubit_count = 1, mid_measurement_count = 1)

Use explicit Op(...) whenever you need keyword arguments such as control=... or noisy=false, or specialized constructors like ifOp, OpQC, and OpF. Single tuples also work directly in apply(state, ("X", 2)), apply(("X", 2)), and ("X", 2) * state. See Operation lists for more examples.

Choose the output you need:

CallReturns
apply(state, ops) / apply(ops; backend=...)Evolved state (or (state, bits) with track_measurements=true)
sample(state_or_ops, shots; backend=...)Raw final outcomes as integers
measure(state_or_ops, shots; backend=...)Device-like Measurement (frequencies, expectations, .mid_measurements)

Omit the shot count in measure(state) for exact probabilities, including on MPS and CAMPS up to 16 qubits. Use Measurement(draws, N) to summarize existing raw draws. Qubit indices start at 1, and qubit 1 is the most significant bit in statevectors and integer measurement outcomes.

Circuit sampling starts each shot in the zero state. Gate noise is passed to apply as noise=..., and to circuit sampling functions as options=Options(noise=...). All circuit entry points (apply, sample, measure, shadow) accept backend=.... Operations run in their supplied order; no layout or SWAPs are added by default. Use route(ops, layout) when connectivity matters. See the operation-list examples for execution, sampling, and saving results.

Choose a workflow

  • Circuit examples: gates, noise channels, measurements, plotting, and the distinction between an ensemble and a single trajectory. The conditional measurement and reset sections explain outcome records and feedback. Later examples cover Hamiltonian evolution, entanglement, partial trace, Pauli twirling, and noise amplification.
  • Backends: detailed guide, runnable examples, and explicit limitations for :statevector, :density_matrix, :tensor (:mps), :camps, and the optional :phasepoly extension.
  • Quantum Machine Learning: VQE, held-out regression and XOR classification, gradient checks, noisy training, MPS truncation, and the complete QML API.
  • Quantum Error Correction: stabilizer codes, logical gates, code distances, noisy syndrome extraction, and magic-state distillation. Worked examples progress from ideal correction to a complete noisy encoded algorithm.
  • OpenQASM import and export: read strings or files, use whole-register operations, preserve idle qubits, and diagnose unsupported input.
  • Function reference: signatures and detailed API documentation.

Installation

Julia 1.10 or later is required. Install from the repository:

using Pkg
Pkg.add(url="https://github.com/aydindeger/BlueTangle.jl")
using BlueTangle

PRIMA_jll version 0.7.1 can fail to load on Linux with glibc 2.41+ with cannot enable executable stack. See the upstream issue. Linux CI uses Ubuntu 24.04 pending an upstream binary rebuild.

For a local checkout, start Julia in its root with julia --project=. and run using Pkg; Pkg.instantiate(); using BlueTangle. Run the tests with julia --project=. -e 'using Pkg; Pkg.test()'.

plotq(ops) prints a boxed text circuit without extra dependencies. For graphical output, install and load PyPlot, then call plotq(ops; backend=:pyplot) and savefigure. plotqt is also available for text output. Loading PhasePoly enables phasepoly for its supported structured noiseless circuits; see the optional backend example.

Install optional packages in the environment where you use them:

using Pkg
Pkg.add("PyPlot")
Pkg.add(url="https://github.com/aydindeger/PhasePoly.jl")

Scope

The package is experimental. Density-matrix evolution sums noise and unobserved measurement branches, whereas vectors and MPS states represent individual trajectories. MPS truncation, finite-shot sampling, and Trotter discretization introduce different approximations; choose and check their settings separately.

The default QEC decoder searches for a single physical Pauli error; the Steane decoder treats each block independently. The QASM importer supports the documented OpenQASM 2 subset. PhasePoly supports a restricted gate family, and its cost can grow exponentially with interior Hadamards or level-4 phase terms. The relevant examples state these limits where they affect the calculation.
